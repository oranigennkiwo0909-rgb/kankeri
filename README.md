# お墓で缶蹴り

真っ暗なお墓を一人称で歩く、缶蹴りの 3D ブラウザゲームです。

▶ 遊ぶ：https://oranigennkiwo0909-rgb.github.io/kankeri/

- かくれる役か鬼の役を選べる。鬼の懐中電灯に照らされたら「みーっけ！」
- 自分のライト、金のうんこ（鬼が 20 秒止まる）、ホラー BGM
- お化けにさわるとゲームオーバー → 観戦するか、やめるか
- 「友達とあそぶ」：同じ合言葉を入れた人どうしでつながる（PeerJS で端末どうしを直接つなぎます。Wi-Fi だとつながりやすいです）

ビルドは不要です。`index.html` をそのまま静的ホスティング（GitHub Pages など）に置くだけで動きます。
