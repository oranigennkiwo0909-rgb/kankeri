# お墓で缶蹴り

真っ暗なお墓を一人称で歩く、缶蹴りの 3D ブラウザゲームです。

▶ 遊ぶ：https://oranigennkiwo0909-rgb.github.io/kankeri/

- かくれる役か鬼の役を選べる。鬼の懐中電灯に照らされたら「みーっけ！」
- 自分のライト、金のうんこ（鬼が 20 秒止まる）、ホラー BGM
- お化けにさわるとゲームオーバー → 観戦するか、やめるか
- 「友達とあそぶ」：同じ合言葉を入れた人どうしでつながる（PeerJS で端末どうしを直接つなぎます。Wi-Fi だとつながりやすいです）

ビルドは不要です。`index.html` をそのまま静的ホスティング（GitHub Pages など）に置くだけで動きます。

# naoの008ゴールデンボール

4 人で撃ち合う一人称シューティング（3D ブラウザゲーム）です。

▶ 遊ぶ：https://oranigennkiwo0909-rgb.github.io/kankeri/golden-ball/

- 「友達と遊ぶ」で部屋をつくり、LINE で合言葉（招待リンク）を送れる。足りない人数は CPU が入る（途中で抜けた人も CPU に交代）
- CPU のつよさ：かんたん / ふつう / むずかしい / 008級
- 顔は好きな画像をはれる。ダメージを受けるほど、あざ・たんこぶ・はなぢ・ほうたいでボロボロ・ボコボコに（救急箱で回復すると少しなおる）
- まん中の台のゴールデンボールを取ると、金の銃で一発でたおせる
- パソコン（WASD＋マウス）とスマホ（タッチ操作）の両方で遊べる

`golden-ball/index.html` だけで動きます（ビルド不要）。
